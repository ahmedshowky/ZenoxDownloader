## 📖 ما هو Zenox Downloader؟

**Zenox Downloader** هو تطبيق مجاني بالكامل لسطح المكتب (Windows) يتيح لك تحميل الفيديوهات ومقاطع الصوت بسهولة تامة من أشهر المواقع على الإنترنت مثل **YouTube** وغيرها.

البرنامج مبني بتقنية **WPF (.NET)** ويستخدم المحرك الشهير **yt-dlp** تحت الغطاء، مما يجعله سريعاً وموثوقاً وقادراً على التعامل مع روابط المقاطع المفردة والقوائم الكاملة (Playlists) في وقت واحد.

## 🚀 طريقة التشغيل

1. حمّل المشروع أو استنسخه:
```bash
git clone https://github.com/ahmedshowky/ZenoxDownloader.git
```

2. افتح المشروع في **Visual Studio 2022**

3. اضغط **Run (F5)** وابدأ التحميل فوراً!

> ملاحظة: ملف `yt-dlp.exe` موجود داخل المشروع مسبقاً ولا تحتاج لتثبيته يدوياً.
